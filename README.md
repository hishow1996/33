## 网页视频处理说明

粘贴普通 HTTP/HTTPS 网页地址后，应用会在内置网页中检测 HTML5 视频元素及常见媒体网络请求。检测到可直接访问的视频地址时，可进入现有播放器，继续执行音频提取、中文转写、翻译、字幕显示与配音流程。

- 直接媒体地址：支持可独立访问的 MP4、WebM 等常见 HTTP/HTTPS 媒体文件。
- HLS（`.m3u8`）：可尝试处理完整、未加密的点播清单；音轨片段会分段缓存，失败后可复用已完成的片段。分段缓存总量受限，并会在成功合并后清理。
- 会话安全：当前网页的 Referer 与 Cookie 只用于当次媒体请求，不写入分段缓存清单；重定向到其他主机时不会继续转发 Cookie。
- 暂不支持：DRM/加密媒体、`blob:`/MSE 临时流、直播或动态 HLS、DASH（`.mpd`）、BYTERANGE 分片，以及需要专有脚本才能获取的媒体地址。受限地址会显示原因，不会尝试绕过保护。
- 设备资源：音轨缓存限制为 160 MB；HLS 清单限制为 2 MB、最多 10,000 个片段。较大或复杂的网页流可能无法处理。

APK 构建工作流目前设置为**手动触发**；普通源码提交不会自动启动构建。
