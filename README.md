## 网页视频处理说明

粘贴普通 HTTP/HTTPS 网页地址后，应用会在内置网页中检测 HTML5 视频元素及常见媒体网络请求。检测到可直接访问的视频地址时，可进入现有播放器，继续执行音频提取、中文转写、翻译、字幕显示与配音流程。

- 直接媒体地址：支持可独立访问的 MP4、WebM 等常见 HTTP/HTTPS 媒体文件。
- HLS（`.m3u8`）：可尝试处理完整、未加密的点播清单；音轨片段会分段缓存，失败后可复用已完成的片段。分段缓存总量受限，并会在成功合并后清理。
- 会话安全：当前网页的 Referer/Cookie 只在运行时用于请求，不写入分段索引文件；音轨缓存下载器手动处理重定向，只有目标主机与源媒体主机一致时才发送 Cookie。
- yt-dlp 兜底：网页检测不到媒体地址时，会自动尝试 yt-dlp 解析（B站、TikTok、Twitter 等上千个网站），也可手动点击「用 yt-dlp 解析本页视频」。首次使用需解包运行时（约数秒）；解析出的地址带站点签名，需立即播放。YouTube 仍优先走内置提取器，风控期可从网页视频入口经 yt-dlp 自救。
- yt-dlp 音频直下：经 yt-dlp 解析的源在转写时会优先用 bestaudio 直接下载纯音频（免下整视频、省流量省电），下载进度会显示在转写阶段；失败自动回落现有流式音频提取。Cookie 仅存内存不落盘。
- yt-dlp 规则自动检测：应用启动与打开设置页时自动检查上游新版本（上午/下午/晚上各一次，深夜静默，仅几 KB 流量）；发现新版本后可在设置「视频源（yt-dlp）」或网页解析失败提示旁一键更新（约 30MB）。
- 仍不支持：DRM/加密媒体、需要登录/会员的内容、直播流。受限地址会显示原因，不会尝试绕过保护。
- 设备资源：音轨缓存限制为 160 MB；HLS 清单限制为 2 MB、最多 10,000 个片段。较大或复杂的网页流可能无法处理。

APK 构建工作流目前设置为**手动触发**；普通源码提交不会自动启动构建。


## 本地翻译模型说明

- ML Kit 语言包由应用按需下载和管理，下载后可离线翻译。
- OPUS-MT 首批支持英语到简体中文。ONNX 权重来自 onnx-community/opus-mt-en-zh，基础模型为 Helsinki-NLP/opus-mt-en-zh；模型卡标注 CC-BY-4.0 许可，需保留模型来源归属信息。模型运行时下载，不打包进 APK。
- OPUS-MT 下载使用临时文件与 HTTP Range 续传；网络中断或暂停后可继续，不要求从头下载。推理仅在所需文件完整后启用。
