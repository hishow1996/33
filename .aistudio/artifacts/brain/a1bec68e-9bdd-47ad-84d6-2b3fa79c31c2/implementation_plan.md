# 免费大模型直接集成至 API 管理列表 (DeepSeek & Google Gemini)

将开箱即用的免费大模型（Google Gemini 与 DeepSeek）直接呈现在 **API 管理主列表** 中，与内置的「Google 翻译」及用户添加的自定义 API 并列展示，支持随时一键点选切换当前翻译服务。

## 用户确认与关键决策

> [!IMPORTANT]
> 根据用户的最新修改要求（Plan action: revise），我们调整了原先仅在添加弹窗中放预设的逻辑，改为**直接常驻在主列表**：

- **展示位置**: 直接放在 API 管理页面的服务列表中（与「Google 翻译」和自定义 API「如 NVIDIA」同层级平级展示）。
- **包含服务**:
  - **Google Gemini**（免费大模型 · Gemini 2.5 Flash 极速翻译）
  - **DeepSeek**（免费大模型 · DeepSeek-V3 智能字幕翻译）
- **交互方式**:
  - 每个免费模型拥有独立的卡片展示，带有专属品牌矢量 Logo、服务类型与状态说明；
  - 用户只需点击卡片或单选框，即可将当前翻译引擎直接切换为该免费大模型；
  - 同样支持切换回「Google 翻译」或用户自行添加的第三方 API（如截图中的 NVIDIA），自由无缝切换；
  - 免费大模型卡片支持查看连接状态与延时测试，亦支持点击「•••」选择「填入个人私有密钥覆盖」。

## 1. 概述与核心价值

- **解决的问题**: 用户无需额外点击右上角「+」进行任何繁琐的添加流程，打开「API 管理」页面就能直接看到并立即选用 DeepSeek 或 Gemini。
- **目标用户**: 既希望零门槛直接用上强大 AI 翻译、又保留自主添加私有 API 切换需求的用户。
- **核心体验**:
  - 列表清晰划分为「内置与免费大模型」与「自定义 API」两大协同板块；
  - 单选机制统合：整个页面始终保持一个当前生效的活跃翻译引擎（高亮显示「当前服务 ✓」）；
  - 全流程开箱即用，无需配置即可调用。

## 3. 关键产品决策与技术选型

- **服务标识与持久化架构**:
  - 定义保留负数 ID 常量：
    - `ACTIVE_ID_GOOGLE_TRANSLATE = -1L`（本地 Google ML Kit 引擎）
    - `ACTIVE_ID_FREE_GEMINI = -10L`（免费 Google Gemini 引擎）
    - `ACTIVE_ID_FREE_DEEPSEEK = -11L`（免费 DeepSeek 引擎）
    - 正数 ID（`> 0L`）：Room 数据库中用户通过「+」号自行添加保存的 `ApiProfile`。
  - 此设计完全向下兼容现有 `SharedPreferences("settings").getLong("active_api_id", -1L)`，无需修改现有数据库实体结构或进行数据库迁移。
- **翻译引擎执行链路 (`TranslationEngine` / `EngineFactory`)**:
  - 在 `EngineFactory` 中扩展负数 ID 的解析分支：
    - `-10L`：构建默认配置的 `GeminiEngine`（端点 `https://generativelanguage.googleapis.com`，模型 `gemini-2.5-flash`）；
    - `-11L`：构建默认配置的 `OpenAiCompatEngine`（端点 `https://api.deepseek.com`，模型 `deepseek-chat`）；
  - 视频播放器和后台配音翻译服务在调用 `EngineFactory` 时无缝衔接，无需重构上层字幕翻译调用代码。

### 具体实施步骤

1. **统一活跃服务选择逻辑 (`EngineFactory & ActiveId`)**:
   - 补充 `ACTIVE_ID_FREE_GEMINI (-10L)` 与 `ACTIVE_ID_FREE_DEEPSEEK (-11L)` 映射；
   - 确保 `PlayerScreen` 和翻译流程通过 `EngineFactory.getActiveEngine(context)` 时能直接获取并执行对应的免费大模型翻译。

2. **在 `ApiManagerScreen` 列表顶部引入免费大模型卡片**:
   - 紧随「Google 翻译」卡片下方，渲染「Google Gemini」与「DeepSeek」专属卡片；
   - 实现点击单选与当前生效「✓」标识联动；
   - 为免费卡片提供快速连接测试弹窗或 Toast 反馈。

3. **保留并增强自定义 API 列表与「+」添加功能**:
   - 用户自建的 API 列表（如已有的 NVIDIA）在下方自然展示，保持原有编辑、停用、删除功能；
   - 右上角「+」仍然可用，供用户随时添加自己的其他定制模型。

4. **编译与功能验证**:
   - 运行 `compile_applet` 进行严格的构建与编译检查；
   - 确保所有页面切换、状态保存与翻译引擎调用均无异常。
